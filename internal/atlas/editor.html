Everything is direct: select a line and every node shows its directional handles. Dragging a handle keeps the pair's ANGLE locked but each side's LENGTH independent (smooth point); alt-drag a handle breaks the angle link — once broken it stays independent (dbl-click twice to re-smooth). Drag nodes to move them, alt-drag a node to pull fresh handles out, dbl-click node = smooth ⇄ corner, right-click node = delete, click mid-segment = insert node.
＋ new line N (pen): click = corner node (sharp angle) · click-drag = pull the curve out (continues the previous curvature) · hold space to pan · Enter/dbl-click finish · Esc cancel.
Continue a line: C (extends the end nearest your cursor), or click its round end anchor twice. Interline: select a line, toggle colours in its panel (one line, many routes). Split X · Merge M (joins two lines end-to-end) · ⌫ delete line · Z/⇧Z undo/redo.
Drawing snaps to other lines' endpoints — build one continuous network across locations.
